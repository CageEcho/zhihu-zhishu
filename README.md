# 知树 · 树上写作与历史树轮 DEMO v8

打开 `dist/index.html`，或双击 `打开知树 DEMO.command`。保留整个 dist 文件夹即可离线运行。每次打开或刷新都会自动清空上一次的演示数据，从首页和一颗空种子重新开始。

## 三个导航入口

- **我的知树**：唯一的写作空间。点击种子导入收藏，根系选择主要观点，枝干展开对话，树叶整理文章，果实查看或发布。
- **历史树轮**：在本次演示中按整棵树保存。支持搜索、按生长状态筛选，点击记录恢复原树；“收藏来源”保留本次采集的内容。
- **同题树林**：查看和交流同题文章，采集内容为新的收藏来源。自己的文章可直接返回所属知识树。

原“一起想清楚”、独立文章编辑页、“我的作品”和“我的资料”页面已移除。旧 thinking / article 地址转向我的知树，旧 works / favorites 地址转向历史树轮。

## 生长与继续创作

一棵树对应一个主题；每篇完成的文章是一颗果实。

- 导入收藏后开始出现在历史树轮中；空种子不会占据记录列表。
- 收藏、主要观点、已保存的对话、输入中的草稿和文章草稿一起保存。
- 历史树轮中可种一棵新树，已有树在本次演示期间继续保留。
- 发布后保留带“已采摘”文字的果柄标记，点击回看文章与发布状态。
- 点击树叶可以补充思考或写下一篇；已有果实与发布版本继续保留。
- 发布后留在树上，由用户选择进入同题树林。多颗果实分别对应不同文章。
- 扎根阶段复用播种页的土壤素材、比例和构图，根系内容叠加在同一块土壤上。
- 树上节点框按结构区分颜色：根系深褐、树干暖棕、叶子绿色、果实红色。
- 结果阶段的果实是圆润高光的红苹果（深红渐变、左上高光、短果柄，无叶），挂在树冠正中，尺寸略小；多颗果实时再缩小。
- 首页使用完整红苹果知识树；根系、树干、树叶、果实四个说明点沿竖线排列，并采用各自语义色。
- 每完成一轮回答长出一个树团；三个树团（assets/canopy-left/top/right.png）直接从完整树冠图中沿树团凹缝切出，形状各不相同但画风一致，并按原始位置叠放，第三团出现后以 0.9 秒交叉淡化切换到完整树冠，几乎没有视觉跳变。
- 从扎根页起，“无种子土壤（assets/soil-seedless.png，由种子土壤用泥土纹理补掉种子得到）+ 真实根系（assets/roots-overlay.png）”是一层固定不变的底层；导入收藏时根系参考短片的表现：从种子下方向下长出，先带白绿色发光，随后褪成褐色，种子在根长好时淡出消失，收藏卡片在根长到位后浮现。根系节点数量与导入的收藏条数一致。
- 同题树林重构为一片共用草地上的树林：每个人一棵同尺寸的树，用生长阶段区分（种子 / 树干 / 树叶 / 红果），我的已发布文章排在第一位并结红苹果；点一棵树在下方切换详情，三个动作（查看 / 提出异见 / 采集为根系）随阶段变化，种子阶段不可提出异见。
- 观点确定后首次进入抽枝页时，在树的位置只播放参考短片 assets/sprout-to-trunk.mp4 土壤线以上的部分（从 0.9 秒的双叶小苗开始：拔高 → 发光的树骨架 → 褪成棕色树干），土壤和根系不变；播放到 3.4 秒时淡入去掉土壤的树干图 assets/tree-bare-trunk.png，播完后淡出短片并浮现节点卡片。短片先用颜色矩阵滤镜把米粉色背景推成纯白，再对裁切容器整体做正片叠底，背景完全透明、页面渐变可透出；短片按末帧树的边界与树干图逐像素对位（宽度、顶部、底部、树干中心误差在 5 像素内），放在土壤层之后并把下边收窄到树干宽度，苗和树干从我们的草丛后面长出；树干与完整树的去土素材保留原图根部的草丛环，落地处与原图一致；不可寻址时先静默快进到 0.9 秒再显示。展叶与结果阶段使用同样去掉土壤的 assets/tree-full-tree.png，整个流程土壤与根系保持同一块。
- 三轮完成后的树冠中央出现无文字的金色发光苹果引导图标（精简版）：约 96 像素的小金盘配苹果剪影，无白边黄边，只有柔和外发光；呼吸光晕轻微起伏，两圈极淡的金环交替向外扩散，无定位角与手型；点击进入生成文章。

## 本地测试服务

运行 `python3 qa/serve.py 4201` 后打开 http://127.0.0.1:4201/#home。该服务对所有文件返回 `Cache-Control: no-store`（改完代码刷新即生效，不会拿到旧的 index.html），并支持 HTTP Range（短片可直接跳转到 0.9 秒）。

## 演示自动重置

页面的业务脚本运行前，`dist/demo-reset.js` 会删除知树 DEMO 使用的 3 个本地存储项：旧版状态、当前树快照和多树历史库。它不会调用 `localStorage.clear()`，因此不会删除同一网站下其他页面的数据。

单次演示中，切换“我的知树 / 历史树轮 / 同题树林”不会丢失进度；只有重新打开或刷新页面才会开始下一次干净演示。

## 演示范围

所有操作只在本次页面演示中临时保存，未接入账户云同步或在线 AI。文章使用本地结构整理。同题树林的发布、异见与采集均为本地演示，不会联系或发布给真实知乎用户。
