## 它解决什么问题

我们收藏了很多内容，却很少把它们变成自己的东西。收藏夹越来越厚，观点却没有长出来。

**知树**把“从收藏到文章”这段路，做成一棵树自然生长的过程：

| 树的部位 | 对应的思考动作 | 你做的事 |
| --- | --- | --- |
| 🌰 **种子** | 起点 | 点击种子，导入 1–5 条收藏 |
| 🪵 **根系** | 材料 | 每条收藏长成一条根，选一条作为回应对象 |
| 🌳 **树干** | 观点 | 写下自己的主要观点，树干从苗长成 |
| 🍃 **树叶** | 对话 | 三轮追问：理由、异见、边界，每答一轮长出一团树冠 |
| 🍎 **果实** | 文章 | 把三轮思考整理成一篇带出处的文章，树上结出红苹果 |
| 🌲 **树林** | 交流 | 摘下果实发布到同题树林，看看别人怎么想 |

口号里的三句话是产品的价值主张：**更少的囤积，更久的沉淀，更像你的观点。**

## 快速开始

```bash
# 方式一：本地服务（推荐，改完代码刷新即生效，支持视频跳转）
python3 qa/serve.py 4201
# 然后打开 http://127.0.0.1:4201/#home

# 方式二：直接打开静态文件
open dist/index.html            # 或双击「打开知树 DEMO.command」

# 运行单元测试
node --test tests/*.test.cjs
```

- 纯静态项目，**无构建步骤、无依赖安装**，保留整个 `dist` 目录即可离线运行。
- 每次打开或刷新页面会自动清空上一次的演示数据，从首页和一颗空种子重新开始（见 [演示自动重置](#演示自动重置)）。
- 推荐视口 1440×900 及以上的桌面浏览器（Chrome / Edge / Safari）。

## 完整流程演示

下面按一次真实演示的顺序截图。所有截图均来自本仓库当前版本。

### 1. 首页

首页右侧是一棵完整的红苹果知识树。四个说明点分别落在根系、树干、树叶和果实上，鼠标悬停显示对应含义，点击后在右下角展开说明。

![首页](docs/screenshots/01-home.png)

### 2. 播种：一颗种子，一片可能

进入「我的知树」，页面中央只有一块土壤和一颗发光的种子。

![种子页](docs/screenshots/02-seed.png)

点击种子，选择 1–5 条收藏导入。演示模式下也可以一键使用 3 条演示收藏。

![导入收藏](docs/screenshots/03-import-dialog.png)

### 3. 扎根：收藏长成根系

导入后，根系从种子正下方向土壤里生长：先带一层白绿色的光，随后褪成褐色，种子在根长好时淡出消失。**每条收藏对应一个根节点**，导入 2 条就只有 2 个节点。

| 根系正在长出 | 根系长好 |
| --- | --- |
| ![根系生长](docs/screenshots/04-roots-growing.png) | ![扎根页](docs/screenshots/05-roots.png) |

点击任意一条根系，阅读这条收藏的观点，然后写下你自己的主要观点。

![写下观点](docs/screenshots/06-viewpoint-dialog.png)

### 4. 抽枝：观点长出了树干

观点确定后，树的位置会原地播放一段从苗到树干的生长短片：双叶小苗拔高，变成发光的树骨架，再褪成棕色树干。土壤和根系全程保持不变，短片播完后无缝交接为树干图，三个枝干节点浮现。

| 小苗冒出 | 树干长成 |
| --- | --- |
| ![小苗](docs/screenshots/07-sprout.png) | ![抽枝页](docs/screenshots/08-branches.png) |

### 5. 展叶：多想一层，就多一片叶

三个枝干对应三轮追问：**理由**（为什么这样想）、**异见**（换个角度呢）、**边界**（何时不成立）。

![对话弹窗](docs/screenshots/09-dialogue-dialog.png)

每完成一轮，树上就长出一团树冠。三个树团直接从完整树冠图中切出，形状各不相同但画风一致，按原位叠放；第三团出现后交叉淡化为完整树冠，没有视觉跳变。

![完成两轮](docs/screenshots/10-canopy-2of3.png)

三轮全部完成后，树冠中央出现一枚呼吸发光的金色苹果图标，引导你把这一树想法写成文章。

![展叶完成与引导](docs/screenshots/11-leaves-guide.png)

### 6. 结果：文章完成，果实才会成熟

点击金色图标进入文章整理。系统把观点、经历、回应与边界整理成结构化草稿，你可以逐段修改；**只有你确认文章，树上才会结出果实**。

| 整理入口 | 文章编辑 |
| --- | --- |
| ![整理入口](docs/screenshots/12-article-dialog.png) | ![文章编辑](docs/screenshots/13-article-editor.png) |

确认后，树冠正中挂上一颗红苹果。

![结果](docs/screenshots/14-fruit.png)

### 7. 发布：摘下果实，进入树林

点击果实可以回看文章，也可以选择一片同题树林把它发布出去。发布是独立于“完成文章”的另一个动作，作品默认私人保存。

| 发布选择 | 已采摘标记 |
| --- | --- |
| ![发布](docs/screenshots/15-publish-dialog.png) | ![已采摘](docs/screenshots/16-harvested.png) |

## 三个页面

### 我的知树

唯一的写作空间，上面的整条流程都发生在这里。同一棵树可以继续补充思考、写下一篇，已有果实和发布版本一直保留。

### 同题树林

同一个问题下，每个人一棵树，并排站在一片共用的草地上。**树的生长阶段就是每个人的思考进度**：种子（只有收藏）、树干（观点已立）、树叶（三轮对话完成）、红果（文章已发布）。我的树排在第一位。

![同题树林](docs/screenshots/17-forest.png)

点一棵树，下方切换到它的详情：作者、阶段、观点或标题、根系来源和阅读 / 异见 / 采集数据。三个动作随阶段变化：

- **查看**：看结论、理由和来源根系
- **提出异见**：针对观点提问，不针对人；作者会在树下回应（种子阶段没有观点，不可提出异见）
- **采集为根系**：把别人的果实种进自己的土壤，保留作者和引用链，不等于认同

![树林详情](docs/screenshots/18-forest-detail.png)

### 历史树轮

每一棵种过的树都留下一圈年轮。刚开始是 0，导入收藏后自动记录，可按生长状态筛选、搜索，点击卡片回到树上继续。「收藏来源」页签保留本次采集的所有内容。

![历史树轮](docs/screenshots/19-history.png)

## 视觉与动效设计

整套视觉围绕一棵 2.5D 黏土质感的树展开，所有阶段共用同一块土壤和根系，保证连续性。

- **固定底层**：从扎根页起，“无种子土壤 + 真实根系”是一层不变的底层；树干、完整树冠都使用去掉土壤的透明素材叠在上面，整个流程土壤不会更换。根系图层直接从最终完整树图中抠出，与最终画面完全一致。
- **根系生长**：导入收藏时，根系从种子下方向下显现，先发白绿光再褪成褐色，卡片在根长到位后浮现。
- **苗到树干**：参考短片只播放土壤线以上的部分，放在土壤层之后，苗从我们的草丛后面长出。短片用颜色矩阵滤镜把原始背景推成纯白，再对裁切容器做正片叠底，背景完全透明。短片末帧与树干图经逐像素匹配对位，交接时几乎没有重影。
- **树团生长**：三个树团沿完整树冠的凹缝用分水岭切出，先画的树团朝后画的方向羽化、后画的向前外扩盖住羽化带，单独出现时边缘柔和，叠齐后完全不透；第二团被切掉的底边由程序合成一段圆润底瓣补全。
- **语义色**：根系深褐、树干暖棕、树叶绿色、果实红色，从首页说明点到树上的节点框、连线和悬停光晕全部统一。
- **果实**：圆润高光的红苹果，深红渐变、左上高光、短果柄，挂在树冠正中。
- **引导图标**：三轮完成后树冠中央出现一枚约 96 像素的小金盘配苹果剪影，无文字、无边框，只有轻微呼吸的光晕和两圈向外扩散的淡金环。

## 技术实现

- **零依赖静态站**：原生 HTML / CSS / JavaScript，无框架、无打包。页面通过 `location.hash` 路由（`#home` `#garden` `#history` `#forest`）。
- **树的场景**：`dist/garden-scene.js` 用一张 1440×900 的固定舞台渲染每个阶段——土壤图、根系 SVG 图层、树干 / 树冠图、节点 SVG、卡片和点击热区都以舞台坐标定位，窄屏时整体居中裁切。
- **状态与存储**：`dist/tree-store.js` 维护多棵树的记录、快照与恢复，并兼容旧版数据迁移；`dist/demo-reset.js` 在业务脚本运行前定向清空知树使用的 3 个本地存储项，不影响同一站点的其他数据。
- **数据**：`dist/data.js` 内置 4 个话题、每个话题 3 位演示知友的文章 / 观点 / 根系 / 异见与回应，以及带来源链接的收藏材料（见 `research/zhihu-sources.md`）。
- **素材处理**：根系、三个树团、去土树干 / 树冠、无种子土壤等透明素材，都由脚本从原始树图中按颜色、连通域和分水岭分割抠出；短片的对位通过冻结末帧与树干图做像素级 IoU 搜索确定。
- **测试**：`tests/data.test.cjs` 校验话题与树林数据的完整性，`tests/tree-store.test.cjs` 覆盖迁移、草稿保留、多树切换、果实保留和保存失败等场景。

```bash
node --test tests/*.test.cjs   # 13 项测试
```

### 演示自动重置

页面的业务脚本运行前，`dist/demo-reset.js` 会删除知树使用的 3 个本地存储项：旧版状态、当前树快照和多树历史库。它不会调用 `localStorage.clear()`。单次演示中，在「我的知树 / 历史树轮 / 同题树林」之间切换不会丢失进度；只有重新打开或刷新页面才会开始下一次干净演示。

### 演示范围

所有操作只在本次页面演示中临时保存，未接入账户云同步或在线 AI；文章由本地结构整理生成。同题树林的发布、异见与采集均为本地演示，不会联系或发布给真实知乎用户。收藏材料的来源记录见 `research/zhihu-sources.md`，页面中的摘要为演示整理，不代表原作者立场。

## 项目结构

```
zhishu-topics-demo/
├── dist/                      # 可直接运行的静态站
│   ├── index.html             # 入口，四个视图
│   ├── app.js                 # 首页、历史、树林、弹窗与动作分发
│   ├── garden.js              # 我的知树：阶段流转、表单、动画时序
│   ├── garden-scene.js        # 我的知树：舞台渲染（土壤、根系、树、节点、卡片）
│   ├── history.js             # 历史树轮
│   ├── tree-store.js          # 多树存储、迁移、快照
│   ├── demo-reset.js          # 演示数据定向重置
│   ├── data.js                # 话题、演示知友与收藏材料
│   ├── styles.css / navigation-v8.css / garden-v7.css / forest-v9.css
│   └── assets/                # 树、土壤、根系、树团、短片等素材
├── docs/                      # README 用图
├── qa/                        # 本地服务、浏览器验证脚本与记录
│   └── serve.py               # 无缓存 + Range 支持的本地服务
├── research/                  # 素材生成记录与知乎来源记录
├── tests/                     # node --test 单元测试
└── 打开知树 DEMO.command      # macOS 双击打开
```
