# 知树 · 知乎真实内容话题 DEMO

这是一版从收藏走向个人文章的知树交互演示，延续蓝白留白、绿色 2.5D 树和“根系—树干—枝叶—果实”的视觉语言。

## 打开

直接打开 `dist/index.html`，或在本目录启动本地服务：

```sh
python3 -m http.server 4191 --bind 127.0.0.1 --directory dist
```

然后访问 <http://127.0.0.1:4191/>。

## 演示流程

1. 首页点击“添加我的收藏内容”，或点击“体验演示资料”进入预置案例。
2. 从“我的资料”打开 4 个推荐话题，查看知树整理的两种观点和 3 条知乎公开来源。
3. 点击知乎原文回查上下文，也可以把话题收藏在当前浏览器。
4. 用三轮问题补充自己的经历、回应和适用条件。
5. 检查观点后整理成可编辑文章草稿；此时枝叶完整，但树上还没有果实。
6. 点击“确认文章，让它结果”，树切换为带 7 枚金橙色果实的状态，文章先私人保存。
7. 再次确认发布后，果实进入对应的同题森林。
8. 查看 3 个预设知友果实，提出具体异见并看到演示回复，或把果实连同作者和上游来源采集为自己的新根系。

## v5 首页与微交互

- 首页按照“左侧产品主张 + 右侧知识树 + 底部四步流程”重新排版。
- 主按钮为“添加我的收藏内容”，支持填写标题、内容摘要与来源链接；新增资料进入“我的资料”。
- “体验演示资料”直接进入 AI 学习边界示例，并保留其余 3 个真实内容话题。
- 首页使用用户提供的透明果实树图片 `dist/assets/tree-fruit.png`。
- 树上提供 4 个可点击圆点：根系对应收藏内容，树干对应主要观点，枝叶对应多轮对话，果实对应确认后的文章。
- 页面使用固定视口外壳。桌面端的关键操作始终位于首屏，较长内容在对应面板内部滚动；移动端仍保留可访问的内部滚动。
- 首页主标语更新为“十年树木，百年树人。温故知新，知树成林。”
- “启动知树”在没有用户新增收藏时为灰色禁用；新增至少一条收藏后变为绿色并可进入思考。
- 底部流程调整为四步：添加收藏、梳理观点、整理成文、同林共创。
- 首页树恢复完整等比显示，树冠、果实、土壤和根系全部位于右侧安全区域内。

每一轮都提供一条与当前话题、当前问题对应的“演示预设回答”。输入框为空时可一键填入；已有内容时会先确认，避免误覆盖。填入后仍可修改，未修改的预设文字会在观点卡和 Markdown 中明确标记为“演示预设”。

## 数据边界

- 12 条内容于 2026-09-13 通过知乎官方 CLI 调用开放平台获取。
- DEMO 保存的是当次获取结果的简短整理和原文链接，打开页面时不会再次请求知乎。
- 页面没有展示完整原文。摘要整理不代表知乎或原作者结论，需点击链接核对上下文。
- 这是公开内容的演示收藏，不是当前账号的私人收藏夹。
- 三轮问题和观点卡整理在浏览器内完成，没有调用在线 AI。
- 用户回答、收藏的话题和观点卡只保存在当前浏览器，不会自动发布。
- 文章草稿、用户确认和同题森林发布是三个独立状态；修改已确认文章后需要重新确认，果实才会更新。
- 同题森林中的知友、文章与互动为明确标注的演示数据；“发布”和“发送异见”也只改变当前浏览器状态。
- 采集知友果实时保留作者、果实与上游来源链；采集不代表认同，也不会直接生成用户观点。

完整来源和采用理由见 [research/zhihu-sources.md](research/zhihu-sources.md)。

首页与果实状态使用用户提供的透明树图，保存为 `dist/assets/tree-fruit.png`。
