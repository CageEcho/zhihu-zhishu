# 知树 · 树上写作与历史记录 DEMO v8.2

打开 `dist/index.html`，或双击 `打开知树 DEMO.command`。保留整个 dist 文件夹即可离线运行。每次打开或刷新都会自动清空上一次的演示数据，从首页和一颗空种子重新开始。

## 三个导航入口

- **我的知树**：唯一的写作空间。点击种子导入收藏，根系选择主要观点，枝干展开对话，树叶整理文章，果实查看或发布。
- **历史记录**：在本次演示中按整棵树保存。支持搜索、按生长状态筛选，点击记录恢复原树；“收藏来源”保留本次采集的内容。
- **同题树林**：查看和交流同题文章，采集内容为新的收藏来源。自己的文章可直接返回所属知识树。

原“一起想清楚”、独立文章编辑页、“我的作品”和“我的资料”页面已移除。旧 thinking / article 地址转向我的知树，旧 works / favorites 地址转向历史记录。

## 生长与继续创作

一棵树对应一个主题；每篇完成的文章是一颗果实。

- 导入收藏后开始出现在历史记录中；空种子不会占据记录列表。
- 收藏、主要观点、已保存的对话、输入中的草稿和文章草稿一起保存。
- 历史记录中可种一棵新树，已有树在本次演示期间继续保留。
- 发布后保留带“已采摘”文字的果柄标记，点击回看文章与发布状态。
- 点击树叶可以补充思考或写下一篇；已有果实与发布版本继续保留。
- 发布后留在树上，由用户选择进入同题树林。多颗果实分别对应不同文章。
- 种子和根系点击后使用贴近节点的上下文卡片，保留场景可见；卡片会在屏幕边缘自动换向，点击卡片外关闭。
- 扎根阶段复用播种页的土壤与种子构图，只叠加根系节点，不切换另一套地景素材。

## 演示自动重置

页面的业务脚本运行前，`dist/demo-reset.js` 会删除知树 DEMO 使用的 3 个本地存储项：旧版状态、当前树快照和多树历史库。它不会调用 `localStorage.clear()`，因此不会删除同一网站下其他页面的数据。

单次演示中，切换“我的知树 / 历史记录 / 同题树林”不会丢失进度；只有重新打开或刷新页面才会开始下一次干净演示。

## 演示范围

所有操作只在本次页面演示中临时保存，未接入账户云同步或在线 AI。文章使用本地结构整理。同题树林的发布、异见与采集均为本地演示，不会联系或发布给真实知乎用户。

## 验证与文件

- `dist/demo-reset.js`：每次加载前定向清空知树 DEMO 数据。
- `dist/tree-store.js`：多树记录、旧数据迁移、快照与恢复。
- `dist/garden.js`、`dist/garden-scene.js`：树上创作及果实。
- `dist/history.js`、`dist/navigation-v8.css`：历史记录和统一导航。
- `tests/tree-store.test.cjs`：迁移、草稿保留、多树切换、果实保留与保存失败检查。
- `qa/v8-verification.json`：浏览器流程验证记录。

检查命令：`node --test tests/*.test.cjs`。
